#  Express Day 1 Project

This is my first backend project using **Node.js and Express.js**.  
It demonstrates basic server setup, routing, and JSON responses.

---

##  Features

- Node.js environment setup
- Express server creation
- Basic routing system
- JSON API responses
- Request/response cycle understanding

---

##  Routes

| Route | Description |
|------|-------------|
| `/` | Home route (Welcome message) |
| `/about` | About page (JSON response) |
| `/user` | User information (JSON response) |
| `/status` | Server status check |
